## 1. 主流程（启动 -> 完成）

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  主智能体  │    │ 计划智能体 │    │ 开发智能体 │    │ 测试智能体 │
│ (编排者) │    │  planner  │    │  developer│    │   tester  │
└────┬─────┘    └────┬─────┘    └────┬─────┘    └────┬─────┘
     │               │               │               │
     │  接收需求文档  │               │               │
     │  ───────────► │               │               │
     │               │               │               │
     │               │  制定开发计划  │               │
     │               │  ─────────►  │               │
     │               │               │               │
     │  取路径        │  返回路径列表  │               │
     │  ◄────────────│               │               │
     │               │               │               │
     │  取出任务1     │               │               │
     │  ────────────────────────────► │               │
     │               │               │               │
     │               │               │  开发 page1   │
     │               │               │  (独立上下文)   │
     │               │               │               │
     │  取路径        │               │  返回修改路径   │
     │  ◄───────────────────────────────────────────│
     │               │               │               │
     │  启动测试       │               │               │
     │  ─────────────────────────────────────────►  │
     │               │               │               │
     │               │               │               │  独立审查
     │               │               │               │  写报告
     │               │               │               │
     │  取判定        │               │               │  返回 PASS/FAIL + 报告路径
     │  ◄───────────────────────────────────────────│
     │               │               │               │
     │  grep 判定行    │               │               │
     │               │               │               │
```

## 2. 修正循环（FAIL 路径）

```
     │  FAIL + bug 缺陷               │               │
     │  ────────────────────────────► │               │
     │               │               │               │
     │               │               │  resume 修 bug │
     │               │               │  (同一 dev#ID) │
     │               │               │               │
     │  追加         │               │  返回修改路径   │
     │  lessons-learned              │               │
     │               │               │               │
     │  resume 重测   │               │               │
     │  (同一 tester#ID)             │               │
     │               │               │               │
     │               │               │               │  追加段到原报告
     │               │               │               │  (串接 bug 缺陷)
     │               │               │               │
     │  取判定        │               │               │  返回 PASS/FAIL
     │  ◄───────────────────────────────────────────│
     │               │               │               │
     │  第 3 轮 FAIL? │               │               │
     │  └─ YES → resume dev 前强制 Context7/Firecrawl 核验 │
     │               │               │               │
     │  5 轮内 PASS?  │               │               │
     │  ├─ YES → 标记 ✅, 进入下一任务 │               │
     │  └─ NO  → 回到"resume 修 bug"  │               │
     │  第 5 轮仍 FAIL → 标记 ⚠️ 进入下一个任务 │
```

## 4. 状态机

```
            ┌─────────────┐
            │   启动       │
            └──────┬──────┘
                   ▼
            ┌─────────────┐
            │  计划阶段    │ ← 仅一次
            └──────┬──────┘
                   ▼
            ┌─────────────┐
       ┌───►│  取出任务    │
       │    └──────┬──────┘
       │           ▼
       │    ┌─────────────┐
       │    │  启动开发    │ ← 新 Agent（新 ID）
       │    └──────┬──────┘
       │           ▼
       │    ┌─────────────┐
       │    │  等待开发    │
       │    └──────┬──────┘
       │           ▼
       │    ┌─────────────┐
       │    │  启动测试    │ ← 新 Agent（新 ID）
       │    └──────┬──────┘
       │           ▼
       │    ┌─────────────┐
       │    │  等待测试    │
       │    └──────┬──────┘
       │           ▼
       │    ┌─────────────┐         ┌─────────────┐
       │    │  判 PASS?   │─ FAIL ─►│  修正循环    │
       │    └──────┬──────┘         └──────┬──────┘
       │           │ PASS                  │
       │           ▼                       │
       │    ┌─────────────┐                │
       │    │  还有任务?   │                │
       │    └──────┬──────┘                │
       │           │ YES                   │
       │           └──────► 取出任务       │
       │                                    │
       │   ┌─────────────────────────────┘
       │   │  resume 同开发 Agent
       │   ▼
       │  （最多 5 次 tester 测试）
       │
       │  全部任务完成
       ▼
┌─────────────┐
│   汇报       │
└─────────────┘
```

## 5. 简明对照

| 场景 | 启动方式 |
|---|---|
| 第一次开发 | 新 Agent |
| 修 bug | resume 同开发 Agent |
| 第一次测试 | 新 Agent |
| 重测 | resume 同测试 Agent |
| 新任务开发 | 新 Agent（**不复用旧任务**） |
| 新任务测试 | 新 Agent（**不复用旧任务**） |
